Floe Actuated Manifolds

Outdoor fluid-routing manifolds for controlled delivery of viscous rooftop deicing fluid.

Overview

Hero image coming soon

The Floe Actuated Manifolds are two hardware concepts for routing viscous deicing fluid through rooftop snow-melt systems. Both are controlled from a central box through wired valve actuation.

The three-valve model supports separate roof zones, while the one-valve model provides the same core function in a simpler package.

Model Variants

3-valve model image
Multi-Zone Three-Valve Model Routes deicing fluid to three controlled outputs for installations that need separate roof zones.
1-valve model image
Single Output One-Valve Model Keeps the same actuation approach in a lower-complexity package for simpler routing needs.

Design & Integration

The manifolds were designed as compact outdoor assemblies that connect into a larger rooftop deicing system. The shared architecture kept the layout consistent across both models while allowing the valve count to change.

Fluid System

  • Routed viscous deicing fluid to rooftop distribution lines
  • Packaged valves, fittings, and manifold hardware for field installation
  • Balanced service access with outdoor enclosure constraints

Controls Interface

  • Integrated wired actuation from the central control box
  • Kept control logic consistent between the 3-valve and 1-valve models
  • Designed around repeatable installation and maintenance workflows

Manufacturing Support

I also created the documentation and internal tools needed to move the designs toward repeatable production, including EBOMs, MBOMs, SOPs, and Airtable-based kit development tools.

Documentation

  • Defined design-level part requirements through EBOMs
  • Built MBOMs for assembly planning and manufacturing handoff
  • Wrote SOPs for repeatable production workflows

Operations Tools

  • Built Airtable tools for kit development and inventory tracking
  • Estimated assembled product weight from kit components
  • Improved visibility into parts, kits, and production readiness

Testing

Testing focused on valve cycling to check repeatable actuation over extended use. The goal was to validate that the valve assemblies could handle the repeated open-close cycles expected in outdoor deicing applications.
